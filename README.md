## ⚙️ 기술 구현 특이사항

- **GSAP 3.12.5 + ScrollTrigger** — 섹션별 가로 스크롤 & scrub reveal 애니메이션
- **Custom Cursor** — `elasticMouse` 탄성 커서 (이동·회전·속도 기반 스케일)
- **CSS `@property`** — `--sk-angle`로 스피닝 테두리 애니메이션 구현
- **Mulmaru / Galmuri11** — 한국어 픽셀 폰트 적용
- **GitHub Pages** 배포 (`.nojekyll` 설정)
